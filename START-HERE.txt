LAURA'S LINGUISTICS - WINDOWS BUILD PACKAGE

This is source code, not an APK. The cloud build has not been confirmed.

1. Download this ZIP on your Windows PC. Right-click it and choose Extract All.
2. Install Node.js LTS from https://nodejs.org/ if it is not already installed.
3. Inside the extracted folder, double-click BUILD-ANDROID.cmd.
4. Follow the Expo device sign-in instructions. Use the molious account.
5. If Expo asks to generate a new Android keystore, choose Yes. Expo stores it for future updates. If existing credentials appear, reuse them.
6. Leave the window open. The build link provides the APK when the build succeeds. Open the APK link on your Android phone to install.

The launcher installs dependencies, runs the source checks, signs into Expo, and submits an APK build. It does not ask Base44 to generate or edit code. If Expo requests a paid upgrade, stop and review before purchasing.
